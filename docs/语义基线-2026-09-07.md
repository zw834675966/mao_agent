## 3. 结论

### 3.1 向量模式实现"翻身"

哈希嵌入的向量模式（Recall@5=0.538, MRR@5=0.407, NDCG@5=0.441）本质上等价于随机排序——512 维伪随机投影不具备语义表示能力，只能靠词汇重叠的偶然性命中。真实嵌入 BAAI/bge-m3（1024-dim）将向量模式提升至 **Recall@5=1.000, MRR@5=0.910, NDCG@5=0.933**，在 26 条 hard 查询上实现**完美召回**（所有 26 条查询的 gold chunk 均在 top-5 内），且 MRR 接近 1.0（gold chunk 平均排在 ~1.1 位）。

这意味着：
- **BAAI/bge-m3 的语义表示能力完全覆盖了历史/工程语料的 paraphrase 查询**。即使查询是"抗战初期，怎样用中日对比说明既不能速胜也不能亡国？"（无「」引文 stem），也能精准定位到《论持久战》的正确 chunk。
- **向量模式从"不可用"（0.538 Recall）跃升至"高度可靠"（1.000 Recall）**，可作为独立检索模式用于生产。

### 3.2 Hybrid 模式提升来自向量腿

Hybrid 从 0.769/0.573/0.621 提升至 0.923/0.756/0.797。但有趣的是，Hybrid 的 Recall@5（0.923）**低于**纯向量模式（1.000）。这是因为 RRF 融合中 BM25 腿（0.731）产生的噪声稀释了纯向量的完美排序——在语义强相关的查询上，BM25 的词汇匹配反而干扰了排序质量。

**建议**：在语义敏感场景（paraphrase 查询、跨文档检索），优先使用纯向量模式；在需要精确术语匹配的场景（如已知文档标题搜索），仍可使用 Hybrid。

### 3.3 BM25 一致性验证

BM25 在两种嵌入下指标完全一致（0.731/0.635/0.660），证明评测框架的确定性：BM25 的 Tantivy 倒排索引不依赖 embedding 维度，仅依赖 Jieba 分词 + BM25 评分，因此在不同嵌入模型下产生相同结果。这是评测可信度的重要锚点。

## 4. 生产建议

| 建议 | 优先级 | 说明 |
|------|--------|------|
| **默认使用 SiliconFlow 嵌入** | P0 | 真嵌入在 hard 集上全面碾压哈希嵌入。512-dim 确定性嵌入仅适合离线 CI 冒烟和快速原型 |
| **推荐 `--mode vector` 为语义查询默认** | P1 | 在 hard 集上纯向量优于 hybrid（BM25 噪声稀释排序）。对已知标题/术语搜索可切换 hybrid |
| **启用 Cohere Rerank 评测** | P2 | 当前数据为 no-rerank 基线。部署 rerank 后预期 Hybrid 指标可接近纯向量水平 |
| **批量 ingest 限速** | P2 | `--batch-size 32` 配合 CLI 内置 100ms 间隔，未触发 SiliconFlow 429 限流（免费层 2000 RPM）。生产 ingest 时保持此节奏 |
| **扩大评测集** | P3 | 26 条 hard 查询 + 15 篇文档的规模有限。在语料扩充后需重新采集基线 |

## 5. 复现命令

```bash
# 1. 重建真实嵌入索引
cargo run --no-default-features -- ingest \
  --corpus-dir corpus_sample15 \
  --index-file .workbuddy/tmp_claude/sf_data/vector_store.bin \
  --tantivy-dir .workbuddy/tmp_claude/sf_data/tantivy_index \
  --embed-provider siliconflow --batch-size 32

# 2. 三模式评测
for mode in hybrid bm25 vector; do
  cargo run --no-default-features -- eval-retrieval \
    --queries-file evals/retrieval/queries_hard.jsonl \
    --k 5 --mode $mode --no-rerank \
    --index-file .workbuddy/tmp_claude/sf_data/vector_store.bin \
    --tantivy-dir .workbuddy/tmp_claude/sf_data/tantivy_index \
    --embed-provider siliconflow
done
```
