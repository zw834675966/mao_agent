## C2. MarkdownParser 移除作者默认值

- **文件路径**：`src/corpus/parser.rs`（定位 `MarkdownParser::parse`，约 L39-L45）
- **现状**：当文档无 `author` frontmatter 字段时，代码将其默认设置为 `"毛泽东"`（中文字符串 `"毛泽东"`），造成 218 篇工程文档被错误署名
- **要做**：移除该默认值，改为：
  - 若文档**完全无 frontmatter** → 返回 `Err(AuthorRequired)` 错误
  - 若 frontmatter 存在但**缺 author 字段** → 允许 `author = None`（Option），在 chunk metadata 里反映
- **TDD 步骤**：
  1. **RED**：在 `tests/parser_test.rs` 新增两个测试：
     ```rust
     #[test]
     fn test_parser_rejects_doc_without_frontmatter() {
         let md = "# 正文\n无 frontmatter 的内容。";
         let res = MarkdownParser::parse(md);
         assert!(matches!(res, Err(AuthorRequired)));
     }
     #[test]
     fn test_parser_allows_missing_author_field() {
         let md = "---\ntitle: foo\n---\n正文";
         let res = MarkdownParser::parse(md).unwrap();
         assert_eq!(res.frontmatter.author, None);
     }
     ```
     跑测试，确认**第一个失败**（当前实现会塞默认值）
  2. **GREEN**：实现上述两种行为
  3. **REFACTOR**：将 `AuthorRequired` 错误类型加入 `src/error.rs`
- **验证**：
  ```bash
  cargo test --no-default-features --test parser_test
  cargo test --no-default-features                    # 整库回归，全 165+ 个测试必须全绿
  ```
- **可能需要连带修改**：如果有 ingest 流程依赖"作者必有值"，在 CLI 输出处补 fallback 到 `"(未知)"` 显示文字，但不要回填进元数据

  2. **批量补 frontmatter 的 `category` 字段**：
     - 对 `corpus/history/*.md`：每篇加 `category = "history"`（若已有则不动）
     - 对 `corpus/engineering/**/*.md`：每篇加 `category = "engineering"`
     - 用 Python 脚本（写到 `scripts/add_category.py`）扫描所有 md，对没有 category 字段的统一插入，**不要覆盖已有值**

  python scripts/add_category.py            # 实际执行
  python -c "
  import os
  def walk(p):
    for r,_,fs in os.walk(p):
      for f in fs:
        if f.endswith('.md'):
          yield os.path.join(r,f)
  no_cat = [p for p in walk('corpus') if 'category' not in open(p,encoding='utf-8').read()[:300]]
  print(f'无 category 的 md: {len(no_cat)}')
  assert not no_cat, no_cat[:3]
